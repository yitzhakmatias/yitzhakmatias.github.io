Política de privacidad

Última actualización: 23 de noviembre de 2026.

Expenses es una aplicación personal de control de gastos. La desarrolla y la usa únicamente Yitzhak Matias Flores, en su propia computadora. No es un servicio para el público.

Qué datos de Google se usan

Con el permiso gmail.readonly (solo lectura), la aplicación lee en la cuenta de Gmail de su dueño los correos de avisos bancarios y las facturas electrónicas adjuntas. De ellos extrae fecha, monto, moneda, comercio o destinatario, banco y número de operación.

Dónde se guardan

Toda la información se guarda en una base de datos local en la computadora del dueño. El permiso de Google se guarda cifrado en esa misma computadora. Nada se envía a servidores propios ni de terceros.

Con quién se comparte

Con nadie. Los datos de Google no se venden, no se usan para publicidad, no se transfieren a terceros y no se usan para entrenar modelos de inteligencia artificial.

Cumplimiento

El uso y la transferencia de información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions o con el botón "Desconectar Gmail" de la aplicación. Los datos locales se borran eliminando la base de datos de la aplicación.
